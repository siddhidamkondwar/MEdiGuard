1. Pipeline

Sources

Synthea

FHIR bundles, clinical pathways, discharge narratives. Source of truth for diagnosis→procedure norms.

CMS DE-SynPUF

Claim volume and provider distribution only. Correlations are degraded by design — not used for clinical norms.

Code sets

SNOMED→ICD-10 map, CPT, PM-JAY HBP 2.2 rates. Small, broadcast.

↓

Ingestion gate core

Validate

Pydantic / pandera schema, types, ranges, required fields.

Deduplicate

Spark dropDuplicates on (claim_id, line_no), window picks latest.

Pseudonymise new

Salted hash of patient id, drop name / address / contact. Makes the DPDP claim real.

Map codes new

SNOMED→ICD-10, CPT→HBP 2.2. Report coverage %.

Normalise cost new

USD→INR at PPP, plus tier / city / lognormal variation. Without this the cost model has nothing to learn.

Profile

Nulls, outliers, coverage → quality_report.

Emits one canonical claim-line schema. The same module is imported by batch and streaming — otherwise the two layers drift and reconciliation fails for the wrong reason.

↓  structured evidence bundle

Agent pipeline — two agents fix

Agent 1 · Reader

Unstructured document → typed fields, Pydantic-validated. Free text is discarded here.

Agent 2 · Reasoner

Typed evidence → cited verdict, ₹ excess, recommendation. Composes language; computes nothing.

The old Agent 2 (consistency checker) duplicated the similarity model and cost a third of the Groq budget. Groq primary, Gemini fallback, backoff and response cache.

↓

Dashboard & feedback

Streamlit

Reads verdicts, provider_risk, streaming_counters, quality_report.

Feedback loop new

Adjudicator decision → MERGE into verdicts → next batch trains the supervised model.

The crux worth defending out loud. Every number in the explanation — ₹35,870, support 0.0009, 98.7th percentile — is computed by rules, Spark and scikit-learn before the LLM is invoked. The model's only job is language. That is what makes "explainable" defensible rather than one black box explaining another, and it is also the prompt-injection defence: the Reasoner never sees free text supplied by the party under investigation.
